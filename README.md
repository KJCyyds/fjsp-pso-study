# 柔性作业车间调度问题 (FJSP) 的粒子群优化算法实现

本项目使用 **Python 3** 实现了一个简易的柔性作业车间调度问题（Flexible Job-shop Scheduling Problem, FJSP），并采用 **粒子群优化算法 (PSO)** 进行求解，最终全自动生成调度甘特图。

## 1. 项目结构
* `main.py`: 核心算法实现与甘特图绘制脚本
* `requirements.txt`: 项目依赖库列表

## 2. 算法核心思路
* **编码方式**：将粒子位置映射为工件的机器选择和工序顺序。
* **适应度函数**：以最大完工时间（Makespan）最小化为优化目标。
* **迭代优化**：通过群体协作与历史最优经验，自动搜索最佳排班策略。
